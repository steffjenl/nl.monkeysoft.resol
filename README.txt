Read your Resol solar and heating controllers (DeltaSol MX, BS, SLT and many more) in Homey. The app connects locally to a KM2, DL2, DL3 or VBus/LAN module over your network. No cloud account is needed.

Add one device per controller, or one device per temperature sensor so you can place them in different rooms. Temperatures, pump speeds, irradiation, flow, operating hours and error status appear automatically. Use flow cards for value changes, errors, lost connection, and values above or below a threshold. Writing a value back to the controller is experimental and disabled by default.
